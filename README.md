# usmivka

Статичен сайт на български за ежедневни вицове, поздрави, пожелания и мини игра „Змия“. Работи без сървърна база данни и без API ключове.

## Стартиране

Отворете папката с Visual Studio Code и стартирайте `index.html` през разширение за локален уеб сървър (например Live Server). JSON съдържанието се зарежда през `fetch`, затова не отваряйте страниците директно с `file://`.

Сайтът използва Tailwind CSS, Font Awesome и Google Fonts от CDN; за пълния визуален стил е необходима интернет връзка. Основното съдържание и играта остават локални.

## Ежедневно съдържание

`generate_content.py` използва само стандартната библиотека на Python. При всяко дневно изпълнение обновява `data.json` с нов хороскоп за всичките 12 зодии, пет вицa, три пожелания за деня, поговорка, факт и полето `last_updated` с часовата зона на България; добавя вицовете към `joke_archive.json`. Повторно стартиране за същата дата не дублира вицове в архива. Хороскопите и пожеланията се генерират локално, без платен API. Страницата с пожелания зарежда секцията „Пожелания за днес“ от този дневен файл, а датата на последното успешно обновяване се показва в сайта.

GitHub Actions workflow-ът `.github/workflows/daily.yml` стартира ежедневно в 03:15 UTC, валидира данните и записва промените в хранилището. Нужно е хранилището да разрешава на workflow-овете запис към съдържанието. За Cloudflare Pages използвай Git integration към същото хранилище и production branch, за да може новият commit с дневните данни да публикува нов build. Провери първото изпълнение през GitHub → Actions → Daily content.

## Функции

- Дневно съдържание, последна дата на обновяване, поговорка, факт, хороскопи, вицове и пожелания.
- Архив с категории, търсене, запазени любими и случаен виц.
- Отделна категория 18+ с 14 вицa и 6 авторски поговорки; текстовете се показват след възрастово потвърждение и са без графични описания.
- Каталог с 50 пожелания в 11 категории и търсене; „Поздравително ателие“ създава редактирани персонални текстове за 17 повода, в 8 стила и 3 дължини.
- Копиране и споделяне на текст; любимите вицове се пазят в браузъра.
- Браузърни игри без инсталиране: „Змия“, „Морски шах“ за двама, игра с памет и тест за рефлекси с локален рекорд.

## Публикуване

Качете файловете в GitHub Pages, Cloudflare Pages или друг статичен хостинг. Запазете относителните пътища към HTML и JSON файловете.

## SEO и индексиране

- Всички активни страници имат уникални заглавия, описания, Open Graph / X (Twitter) метаданни, икона и локализация за български език.
- `seo.js` добавя каноничен HTTPS адрес според действителния адрес на публикувания сайт и структурирани Schema.org данни (WebSite, Organization, WebPage / CollectionPage и списъци за съдържанието). При локално отваряне с `file://` канонични URL адреси не се генерират.
- `code_artifact.html` е стар дублиращ се макет и е маркиран `noindex`, за да не конкурира страницата с актуалните пожелания.
- `robots.txt` позволява обхождането на сайта. След като сайтът има постоянен HTTPS домейн, създайте валиден sitemap с командата `python generate_sitemap.py https://ВАШИЯТ-ДОМЕЙН` от основната папка на проекта; след това добавете пътя към sitemap-а в `robots.txt` и изпратете адреса му в Google Search Console.
- Потвърдете собствеността на домейна в Google Search Console чрез DNS записа, който Google предоставя. След публикуването проверете HTTPS, canonical URL адресите, sitemap и важните страници с URL Inspection. Метаданните подпомагат разбирането и споделянето на страниците, но не гарантират индексиране или конкретна позиция.
- `social-preview.svg` е социалната графика за споделяне; проверете я с инструментите за визуализация на избраната социална мрежа след публикуване, тъй като поддръжката на SVG за Open Graph варира.
